# C++ Snake-Game

A console-based Snake game written in C++.

## Features

- Arrow-key movement
- Boundary and self-collision detection
- Randomized candy generation
- Progressive snake growth
- Score and turn tracking
- Modular console input and rendering

## Concepts Demonstrated

- Object-oriented programming
- Singly linked lists
- Dynamic memory management
- Modular class design
- Keyboard input handling
